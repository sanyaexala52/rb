
# Как это запустить:
Установите драйвер ODBC Driver 17 for SQL Server (или 18), если он еще не установлен в системе.

Установите библиотеку Python: pip install pyodbc.

Запустите init_db.sql в вашей СУБД, чтобы создать базу.

В файле main.py в переменной server укажите имя вашего сервера, а также логин/пароль (если не используете Windows Authentication).

Запустите main.py.
